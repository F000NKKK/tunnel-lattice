# Support

Thank you for your interest in Tunnel Lattice.

## Getting Help

- **Questions and discussion:** Use [GitHub Discussions](https://github.com/F000NKKK/tunnel-lattice/discussions) for general questions, ideas, and design discussion.
- **Bug reports and feature requests:** Use [GitHub Issues](https://github.com/F000NKKK/tunnel-lattice/issues) with the appropriate issue template.
- **Security issues:** See [SECURITY.md](SECURITY.md) for the responsible disclosure process. Do not report security issues via public issues or discussions.

## Project Status

Tunnel Lattice has published `0.4.0` and has a working crate architecture
(see [ARCHITECTURE.md](ARCHITECTURE.md)), but nothing in the public API is
frozen — a future `0.x` release may still change it (see
`versioning.md`'s pre-1.0 policy). Questions about direction and design are
welcome alongside ordinary usage support.
